# Number Rhyme System


Like the [NumberShapeSystem](/memory-technique/number-shape-system), the number rhyme system replaces hard to visualise numbers with easy to remember images. In this case however it is the sound of the number rather than the shape which provides the link from the number to the image.

An example of the numbers zero to nine converted to the number rhyme system would be.

0\. Nero (Zero)

1.  Bun (one)
2.  Shoe
3.  Tree
4.  Door
5.  Hive
6.  Sticks
7.  Heaven
8.  Gate
9.  Vine

The number rhyme system can be used on its own to remember individual numbers, as a peg system to provide ten more hooks to hang useful facts and items or as a supplement to other memory systems to remember single digit numbers.
