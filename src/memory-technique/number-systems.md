# Mentat Wiki: Number Systems

Numbers are particularly difficult to remember, unless you know the trick to them. Fortunately there are many different techiques that can be used with numbers, from the simple [NumberShapeSystem](/memory-technique/number-shape-system) or [NumberRhymeSystem](/memory-technique/number-rhyme-system) systems up to the more sophisticated, but powerful [MajorSystem](/memory-technique/major-system).

In each case the trick is to convert difficult to remember numbers into easy to remember images using colour, exaggeration, size, movement, smell, taste, texture and other senses.
